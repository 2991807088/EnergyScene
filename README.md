# EnergyScene

新能源场景的交互式 3D 可视化项目，围绕不同天气和昼夜条件下的风电、光伏场景展开。

## 场景说明

- 场景包含风力发电机组和光伏电站，可切换晴天、下雨、下雪、大雾及白天、夜晚。
- 可调节风力等级，观察风机叶片转速随风力变化；天气变化会影响天空、光照、雾效和雨雪粒子效果。
- 项目目标是展示不同天气条件下新能源的发力情况。当前版本侧重场景可视化，尚未提供风电、光伏的发电功率或发电量计算与对比数据。

## 技术栈

| 类别 | 技术 |
| --- | --- |
| 前端 | React 19 |
| 3D 渲染 | Three.js、React Three Fiber、Drei |
| 构建工具 | Vite 8 |
| 样式 | Less |

## 本地运行

```bash
npm install
npm run dev
```

开发服务默认使用 `5173` 端口。构建和预览命令：

```bash
npm run build
npm run preview
```

进入页面后，可通过操作栏切换时间、天气和风力；在 3D 场景中拖拽旋转、滚轮缩放、右键平移。
