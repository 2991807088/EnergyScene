## 夜空月亮改为弯月（纪念下令：切换黑夜时天空应出现弯月而不是圆的太阳）

- 夜里那个「圆太阳」不是 `<Sun>` 网格（那是白天专用，`visible={mode==='day'&&weather==='clear'}`），而是 skybox 调色板里的 `disc` 圆盘。
- 改动（仅 2 个文件）：
  - `src/three/skybox.js`：`SKY_KEYS` 新增 `crescent`；`makeSkyPre` 预计算平移后的「暗盘」方向（切向 = UP×DIR，取水平方向让月牙两头朝上下）；`skyPixel` 盘分支改为 `d0 × (1 − 暗盘)`，即月牙 = 圆盘 − 平移同半径暗盘。crescent=0 时完全走原路径（白天不受影响）。
  - `src/three/environments.js`：day 加 `crescent: 0`；night 加 `crescent: 0.7`（月牙最宽处≈月盘直径 35%）。天气预设（weather.js）不用动，雨/雪/雾的 skybox 覆盖项会从昼夜基准继承 crescent。
- 校验（`.tmpcheck/moon.mjs`、`render-face.mjs`）：用生产 `skyPixel/makeSkyPre/paintFaceData` + 双探针调色板精确恢复盘覆盖度 d0。结果：白天晴/雨整圆 100%、左右对称；夜晴月牙占整圆 28.9%、只亮左半、暗侧与「无盘」逐位相同；夜雨/雪/雾继承 crescent=0.7。`npm run build` 通过。
- 经验：探针法 `d0 = (x−y)/(1−y)`（sunColor 设 [1,1,1]、glow/cloud/stars 关掉、disc 1 vs 0 两次求值）可精确测天空盒圆盘几何；亮度差法在亮色天空下会失真（天光比日面还亮）。

## 火电站烟囱冒烟（纪念下令：火力发电站的烟囱需要冒烟效果）

- 新增 `src/three/smoke.js`：烟羽模拟。`SMOKE` 参数集中可调（96 粒/根、寿命 9~14s、上升 62m、尺寸 4.5→22、opacity 0.34、风向 [-0.88,0.47] 朝城市吹）；`makePuffTexture` 用 6 团不同半径柔边圆叠出不规则烟团轮廓；`createPlume`/`updatePlume`。
- **核心取舍：位置按「年龄」解析式求，不做逐帧累加位移。** 好处：出生时间可随机打散，进场景第一帧就是完整烟柱；掉帧/切标签页回来不会因一次性补巨大 dt 而炸开。
- 新增 `src/components/SmokePlume/index.jsx`：Points + ShaderMaterial。逐粒子 `aSize/aAlpha/aRot`（片元里旋转 gl_PointCoord）；`gl_PointSize = aSize * uScale / -mvPosition.z`，`uScale = 画布物理高 / (2·tan(fov/2))`，把 world 单位换算成像素。
- 着色器沿用 three 官方 chunk：`fog_pars_vertex/fog_vertex`（**变量必须叫 `mvPosition`**）、`tonemapping_fragment`、`colorspace_fragment`、`fog_fragment`。`toneMapping()` 与 `linearToOutputTexel()` 由渲染器 prefix 自动注入，**不需要**（也不能重复）include pars。`fog:true` + `UniformsUtils.clone(UniformsLib.fog)` 才能让烟在雨/雪/雾天被雾吃掉。
- `<shaderMaterial args={[props]} />` 的 props 必须 useMemo，否则 r3f 每次渲染重建材质。
- 接线：`northPlant.js` 抽出 `PLANT.stacks`（x 151/157、z -216、r 1.6、h 36）+ 导出 `stackMouths()`（y = PAD + h - 0.6）；`NorthPlant` 收 `wind` prop；`Scene/index.jsx` 传 `<NorthPlant wind={wind} />`。
- **校验方法（本机 Chrome 起不来）：** 沙箱里 headless Chrome 会因 `sandbox initialization failed / GPU process isn't usable` 直接挂，浏览器验证走不通。改用 Node 静态+运行时校验：① 用 `THREE.ShaderChunk` 展开所有 `#include` 确认不缺失、核对符号顺序；② `new THREE.ShaderMaterial({...})` 吞掉 console.warn 确认无告警且 `fog===true`；③ 把 smoke.js 的 `from 'three'` 替换成绝对路径后 import 进 Node，跑 3600 帧检查 NaN / 高度 39.4→100 / 漂移 54m / alpha 在界内 / 首帧 66 颗可见。`npm run build` 通过。
